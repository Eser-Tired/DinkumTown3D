另一台电脑先从原作者页面下载指定ZIP，再在游戏项目根目录运行：

powershell -ExecutionPolicy Bypass -File tools/install_emace.ps1 -ZipPath "C:\Downloads\SlavicWorldFree_Godot_2026-09-06.zip"

# Godot不在默认位置时增加：
# -GodotPath "C:\Tools\Godot\Godot.exe"
